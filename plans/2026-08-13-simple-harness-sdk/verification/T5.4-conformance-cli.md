## Implementation Notes

### Design Decisions

1. **Protocol Version 1.0.0**
   - Indicates stable SDK release
   - Semantic versioning for clear compatibility signaling
   - Major version match required for conformance testing

2. **Pytest Plugin Auto-Registration**
   - Uses `pytest11` entry point for automatic discovery
   - No explicit import required in conftest.py
   - Fixtures available to all tests when plugin installed

3. **Host Factory Pattern**
   - `module:factory` specification for flexibility
   - Factory function called to create host instance
   - Enables custom initialization logic in host implementations

4. **Suite Organization**
   - Four suites: provider, tool, runtime, workflow
   - Comma-separated selection for test targeting
   - Extensible for future suite additions

5. **JSON Report Format**
   - Contains protocol_version, host spec, suites, status, message
   - Machine-readable for CI integration
   - Optional output (only when --json specified)

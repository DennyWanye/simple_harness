## 6. 已知限制

见《交付-不支持项-草稿-2026-10-31.md》。要点：不迁移旧库；一个 SDK 实例只服务一个人；不承诺模型请求物理恰好一次；运行期加工具要重开宿主；任务里的连接器操作照旧走申请单；会话树只有一层；不改在跑的任务。

opt.225 新发现、未处理：人的回答在任务记录里的身份名是 `local-user:legacy_local_profile`（桌面端伴侣身份的旧名），模型汇总时可能据此说"来源是本地资料"——这是 Host 侧命名，SDK 原样记录；手机端用自己的 principal 名字即可。

## 7. 给 AIPhone 的接入步骤

1. 换轮子、换数据根；先 `capabilities()`，确认 `child_sessions / child_result_mirroring / child_request_mirroring / continuation / authorization_port` 在列。
2. 还是只打开一个 `main` 会话。工作会话由模型按用户一句话自己开（`create_child` + `delegate_task`），手机不用新 IPC 目标。
3. 事件流只订阅主会话：`delegated / task_progress / result_ready / needs_response / turn_committed / text_delta`。`needs_response` 与 `result_ready` 若带 `child_key`，界面标出是哪个工作会话；审批类另带 `kind`（review / arbitration / action / source_change）决定按钮。
4. 任务列表用 `tasks()`（子任务带 `child_key`）；人的作答一律 `respond(request_id, decision, version, ...)`，版本是字符串化的 60 位整数，原样回传。
5. 结果通知由人 `ack(event_id)`；自动汇总会自己起一个只读回合把结果说给用户，手机不用再触发。
6. 语音：Service SDK 0.3.20 不变；等中继部署后重跑 A09～A11。

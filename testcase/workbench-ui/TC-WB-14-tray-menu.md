# TC-WB-14 — 托盘菜单三项（B10 专门用例）

> 对应 AC：WB-1（品牌/托盘面，plan T14）｜ 行为契约：**B10（托盘三项——本用例即其专门步骤）**
> manual_required: true

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 启动应用，点击 mac 菜单栏托盘图标。 | 托盘菜单弹出，含**三项**：「显示主窗」「隐藏主窗」「退出 Simple Harness」；**不得**出现旧文案「显示桌宠」「隐藏桌宠」「退出 DeskPet」。 |
| 2 | 主窗可见时点击「隐藏主窗」。 | 主窗隐藏（不在屏幕上、不被销毁——应用仍在运行，托盘图标仍在）。 |
| 3 | 点击「显示主窗」。 | 主窗重新显示并前置，内容与隐藏前一致（会话/视图状态未丢）。 |
| 4 | 点击「退出 Simple Harness」。 | 应用完全退出：窗口关闭、托盘图标消失、进程退出（`pgrep` 核对无残留主进程与 backend 孤儿进程）。 |

判定：四步全部满足才 PASS；任一旧文案残留即 FAIL。

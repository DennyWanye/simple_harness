## 过程中的坑

- vitest 默认把 CSS 置空，`?raw` 也是空串；放行规则要匹配带查询串的 id。
- macOS 临时目录 `/var` 是 `/private/var` 的链接，画廊构建要用真实路径。
- 前端直接引入 tauri-app 之外的 SDK 契约 JSON，导出旧提交副本时要一并带上。
- 探针若整份执行原模块会有副作用（main.tsx 挂载根节点），只取用到的声明。
- prettier 会把 `{" "}` 改写进 JSX 文本，语法树比对要按 React 的 JSX 空白规则规整子文本。
- 提交前看暂存区：补前缀提交一度误带两个已重转文件的改动，当即改正（未合并分支上 `--force-with-lease`）。

`from_json` 规则：走 `fields_of` + `enum_of` + `hash_hex` + `index(..., minimum=1)` + `json_value`；未知键 → `ContractError`（将来 codec 映到 `UNKNOWN_FIELD`）；`schema_version` 必须为 1；`decision_type` 大小写严格；`payload` 按 type 校验精确键集。

**模型 Core Fields 仅第 13 节那 10 个键。** `decision_id` / `request_id` / `mission_id` / `plan_revision` 等不得出现在 Envelope JSON。出现 → 未知键拒绝。

Assumption 不得变成 Fact/Observation/TRUE：`AssumptionV1.from_json` 禁止 `polarity`/`truth`/`kind` 等键。

### JSON Schema 要点

- `$schema`: `https://json-schema.org/draft/2020-12/schema`
- 顶层 `required` 与 V2 第 14 节十字段一致
- `decision_type` enum 九值
- **必须**写 `$defs`：`planningRef`, `versionedTypeRef`, `assumption`, `uncertainty`, `alternative`, `replanTrigger`, 以及各 payload
- `if/then` 或 `allOf`+`if` 实现 `decision_type → payload`
- `reason_refs` `maxItems` 32、`uniqueItems` true
- `subject_key` minLength 1 maxLength 256
- `rationale` minLength 1 maxLength 4000
- **没有** `fact` kind

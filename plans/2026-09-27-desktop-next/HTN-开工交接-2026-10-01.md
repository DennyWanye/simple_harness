## 六、操作配方

**SDK 测试**（在 `sdk/simple-harness-sdk` 下）
```bash
uv run --frozen --group dev --extra local-capacity pytest -q -p no:cacheprovider <测试文件或目录>
```
- 改了 SDK 源码后、跑 `taskgraph_exec` 相关测试前要重新生成部署清单：
```bash
uv run --frozen python scripts/build/taskgraph_manifest.py generate --upstream ../../.local-test-evidence/2026-09-27/batch2a-upstream/evidence.json
```
- 多条命令串起来时用 `bash -c '…'`（zsh 不拆分变量）；含中文的 Python 内联脚本会撞终端编码，写成文件再跑。

```bash
scripts/release_sdk_opt.sh <旧号> <新号> "SDK opt.<新号>：<说明>"
```

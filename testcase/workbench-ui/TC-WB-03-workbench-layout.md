# TC-WB-03 — 工作台布局与四视图导航

> 对应 AC：WB-3 ｜ 行为契约：B6（部分：设置/技能页面化入口）
> manual_required: true

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 启动应用，观察左侧栏。 | 侧栏含三个导航项：💬会话、🧩技能、📄产物；侧栏**底部**另有 ⚙️设置 入口。 |
| 2 | 依次点击 会话 → 技能 → 产物 → 设置。 | 右侧内容区依次切换为 Chat / Skills / Artifacts / Settings 四个视图；每次切换后**当前项有可辨识的高亮态**（与非当前项外观有明确差异，截图留证）；视图为主窗内页面切换，不弹新窗、不弹浮层遮罩。 |
| 3 | 从设置切回会话。 | 聊天视图恢复显示，之前的消息流仍在（chat 视图状态不因切页丢失：滚动位置/已渲染消息不清空）。 |
| 4 | 将窗口缩到最小尺寸 800×560，重复步骤 2 的四次切换。 | 每个视图在 min 尺寸下布局不破：无横向滚动条、侧栏导航项不重叠不被截断、内容区主要控件（输入栏/列表/保存按钮）可见可点。截图四视图各一张。 |
| 5 | 在侧栏「更多」组**逐一点击**记忆、Trace、反馈三个入口，每个打开后再关闭。 | 三个入口各自的弹窗/面板**正常打开且可关闭**（内容渲染无报错，关闭后回到当前视图）；侧栏底部有连接状态徽章。仅"入口存在但点了没反应"= FAIL。 |
| 6 | **快速循环切换压力**：以尽可能快的手速将四视图循环切换 **≥10 轮**（会话→技能→产物→设置 ×10），随后回到聊天视图发送一条消息：`切换压力验证`。 | 回复**仅渲染一次**（消息流无重复气泡）；会话列表**无重复条目**；打开 devtools 控制台核对**无新增报错**（chat 常挂载 + 其余按需挂载不因反复 mount/unmount 泄漏订阅——重复渲染/重复条目是双订阅的招牌症状）。 |

判定：步骤 1–6 全部满足才 PASS；步骤 5 任一入口缺失或打不开记 FAIL（only-add 例外清单之外的功能减少）。

## 步骤6 最大化/还原（maximizable）
**平台语义偏差（如实记录，非缺陷）**：本窗口绿钮的 AX subrole 是
**AXFullScreenButton**（不是 AXZoomButton）——这是 macOS 的默认约定：绿钮=全屏。
两种能力分别实证：
- **全屏**：按 AXFullScreenButton → geom 变为全屏态；Cmd+Ctrl+F 退出 →
  **精确还原 235 111 1100 740** ✓
- **最大化(zoom)**：Window 菜单 → **Zoom** → geom = **0 33 1470 923**
  （填满菜单栏以下整屏）；再次 Zoom → **精确还原 235 111 1100 740** ✓
  （Option+绿钮 在本构建下无效，已实测并记录）
⇒ TC 该步要判的性质「窗口可最大化/还原（maximizable）」**成立** ✓；
  差异仅在于触发控件是 Window→Zoom 而非绿钮直接点击，属 macOS 平台约定。
证据：r7-S01-06-fullscreen.png / r7-S01-06-zoomed.png

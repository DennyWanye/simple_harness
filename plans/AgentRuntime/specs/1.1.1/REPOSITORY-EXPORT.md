# 仓库文档版导出说明

本目录保留计划正文、接口合同、Schema/SQL、参考源码、测试源码与文字评审。原始机器测试报告不进入 Git，嵌套历史 ZIP 由相邻版本目录替代。

原 ZIP 的 SHA-256 和逐项省略索引见 REPOSITORY-EXPORT.json；原交付清单保存在 UPSTREAM-DELIVERY-MANIFEST.json。当前 DELIVERY-MANIFEST.json 已按仓库文档版重新计算，不冒充原 ZIP 的完整副本。保留文件除当前交付清单外均保持原始字节；本说明与导出索引是新增文件。

VALIDATION.md 中的结果是交付作者在当时环境的报告，不代表本机或产品验收。本目录中指向 reports/ 或历史 ZIP 的旧链接仅用于历史追踪，相关原始证据仅保留本机。当前施工请使用 ../1.1.1/。

# TC-WB-15 — 空态：无历史会话 / 无产物

> 对应 AC：非功能「空态」条款（承接 WB-5 / WB-7）
> manual_required: true
> 前置：**全新隔离 user-data 目录**冷启动（保证零会话、零产物；不得手工删库模拟）。

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 用空隔离 user-data 启动。**预期首启路径**：会先经过 StartupOverlay 与 onboarding 向导（行为契约「明确不变」项——两者保留，onboarding 文案品牌残留另立需求不在本用例判定面）；按向导完成必要首启流程后，展开侧栏「会话」区。 | StartupOverlay/onboarding 正常出现并可走完（不因改版丢失或卡死）；完成后会话列表显示**空态引导**（有文案引导新建会话，非空白区域、非报错、非无限 loading）。 |
| 2 | 点击侧栏「📄产物」。 | ArtifactsView 显示**空态**（明确的"暂无产物"类文案/占位，非空白、非报错；artifacts 目录不存在时不崩——返回空列表语义）。 |
| 3 | 从空态引导新建一个会话并发送一条消息。 | 会话空态消失，列表出现首个会话条目（空态→非空态转换正确）。 |
| 4 | 切回产物视图。 | 仍为空态（发消息不应凭空产生产物）；若该消息产生了真实产物文件，则列表出现该产物（两种结果都可判：以 `<user_data>/artifacts` 目录实际内容为准对账）。 |

判定：步骤 1–3 全部满足才 PASS。

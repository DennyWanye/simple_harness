# TC-WB-05 — 侧栏会话列表

> 对应 AC：WB-5 ｜ 行为契约：B3
> manual_required: true
> 前置：user-data 内已有 ≥2 个历史会话且标题/时间可区分（若无：先用 TC-WB-04 步骤 1 造两个会话，各发一条内容可区分的消息，如"会话A标记语句"/"会话B标记语句"）。

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 展开侧栏「会话」区。 | 历史会话以列表展示，每项含标题（或首句摘要）与时间；排序为**时间倒序**（最新在最上，与已知创建顺序核对）。 |
| 2 | 点击较旧的那个历史会话。 | 聊天视图加载该会话消息记录：能看到之前发过的标记语句原文与助手回复；不混入其他会话消息。 |
| 3 | 点击另一个历史会话。 | 消息流切换为该会话内容；步骤 2 的会话内容不残留。 |
| 4 | 点击「新建会话」入口。 | 出现新的空会话（消息流为空/空态引导）；会话列表出现新条目并位于顶部。 |
| 5 | 在新会话发送一条消息：`新建会话往返验证`。 | 后端真实往返成功，回复归属**新会话**；切回旧会话再切回来，该消息仍在新会话中（真的开了新会话，不是复用旧 sid）。 |
| 6 | （能力不减抽查）对任一会话执行重命名与删除操作。 | 重命名后标题更新且切换会话后保持；删除后条目消失且不再可加载。 |

判定：步骤 1–5 全部满足才 PASS；步骤 6 失败记 FAIL（B3 声明协议不变、功能同位迁移）。

# 交付物：不支持项（草稿，发版前定稿）

日期：2026-10-31 起草。对象：AgentOS 合同 v1.0 与 AIPhone 统一交接里**这一轮明确不做或只做一部分**的项，以及原因与替代。开发期口径（用户 2026-10-30 定）：对外不承诺数据兼容、迁移、回退。

| 接入方要的 | 本轮做法 | 原因 | 接入方该怎么办 |
|---|---|---|---|
| SDK-15 opt.222 兼容调用、旧 store 原地升级 | 不做迁移、不做回退。新版本遇到旧库报 `incompatible_store_version`；`capabilities()` 给协议版本与配置版本 | 开发期，每次池身份变更都是新根 | 新版本用新数据根；先读 `capabilities()` 再决定能不能启动 |
| 一宿主多当事人 / 多人共用一个 Agent | 不做。一个 SDK 实例 = 一个 Agent 个体，只服务一个人；这个人是谁由接入方维护 | 用户 10-30 定 | AgentOS 每个成员起一个宿主实例 |
| 模型请求"恰好一次" | 不承诺物理恰好一次；承诺同 key 不重复结算、费用可多算不可少算、不明费用保留可追溯 | 线路取消后结果不可知，只能记"不明" | 以回执与计量账为准对账 |
| 运行期加工具不重开宿主 | 不做（阶段 3 之后） | 工具说明是池身份的一部分；本轮先把目录版本化与 ToolSearch 做出来 | 工具变更后重开宿主 |
| 任务里的连接器走法改动 | 不动。任务里的 `action:` 要求照旧走申请单→审阅→审批→执行 | 两条路共用一个连接器实例与一张效果账本即可 | 主会话小事用动作工具，任务里的副作用照旧 |
| 语音 F2 中继协议错误 | SDK 侧不改；中继修复已推 tokenSeller main，部署在另一台电脑 | 根因在中继编解码 | 等中继部署后手机复验 |
| 压缩 / 上下文换代后的"原文可回读"（SDK-13 / A12） | 本轮按阶段 3 的恢复报告做到：关系、授权、回执摘要规范字段一致、待结果仍消费；原文回读走历史接口 | 不另造压缩机制 | 用 `history()` 与收件箱读原文 |
| 浏览器断线语义（SDK-10 / A06 的一部分） | SDK 不感知前端连接；断线不取消任何东西 | 前端连接不是 SDK 概念 | 接入方自己在重连后重开会话号即可 |

发版前把"待发"任务书落地后的实际情况再核一遍，这张表只留真正没做的。

## 5. 操作配方

### 5.1 SDK 出版本（每改一次 SDK 源码都要走完）

在 `sdk/simple-harness-sdk`：
1. 改 `src/agent_orchestrator/version.py` 与 `src/simple_harness/version.py` 的 `+opt.N`。
2. 重新生成部署清单：`uv run --frozen python scripts/build/taskgraph_manifest.py generate --upstream ../../.local-test-evidence/2026-09-27/batch2a-upstream/evidence.json`
3. `git add` 自己改的 src/tests 文件（有别人在同目录写测试时按文件名加，不要 `-A`），提交。
4. 构建：`uv run --frozen python scripts/build/development_candidate.py --output ../../backend/vendor`（要求工作树干净），记下 `manifest_sha256`、`commit`；`taskgraph_manifest.py verify --wheel <whl>`；`shasum -a 256 <whl>`。
5. Host 钉版（`backend`）：`deskpet/sdk_adapters/sdk_candidate.py` 改版本、wheel 哈希、清单哈希、源提交；`pyproject.toml` 里 `opt.N-1→opt.N`；`git rm` 旧 vendor 两个文件；`uv lock`；`uv sync --inexact`。
6. 钉版测试：`uv run --frozen python -m pytest -q -p no:cacheprovider tests/sdk_adapters/test_sdk_source_identity.py tests/sdk_adapters/test_sdk_candidate.py tests/orchestration/test_deployment_manifest.py tests/sdk_adapters/test_composition.py`，通过后提交"钉 SDK opt.N"。

### 5.3 真机点击（computer-use）

- 应用 bundle id `com.dennywanye.simpleharness`，已授权。后台模式用 `app_screenshot`/`app_click`/`app_type`（坐标系 1568×746）。启动后先点「主对话」再点「任务编排」，列表才连上。
- 新建任务：点「新建任务」→ 目标框约 (1000,87)、成功条件框约 (1000,167)（每行一条；发布写 `action:file_publish.publish:<文件名>`）→「提交任务」约 (1003,329)。纯内容任务 Host 自动确认；带发布的要在「完成要求与操作」里勾内容项、「添加必须完成的效果」、勾 action 项、选所属目标与完成标准「文件已发布，并已读取核对内容」、点「确认上述完成要求」。
- **下拉框**：后台模式打不开原生下拉。做法：`app_release` 后用全屏 `computer_batch` 发按键——先让焦点落在下拉框（shift+tab 移动，zoom 确认有焦点框），`space` 打开，`down` 选择，`return` 确认。全屏模式下鼠标点击常被"程序坞"透明层拦截，所以用键盘。每次按键前先 zoom 确认焦点，曾因点击没送达把 Tab/空格按到了「取消任务」上。
- 提交操作：选好候选后 Tab 到「提交此操作供审查」、空格；批准按钮在审查通过后出现（先 zoom 核对目标文件与目录）。
- 前端打开任务详情后常卡几秒（点击显示 rung1-skipped 即未送达）：等一会或重启应用。

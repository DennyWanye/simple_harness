== 改动 2：新增全幅铺图布局 image_full ==
- VALID_LAYOUTS 元组加 "image_full"。
- 新增渲染器 _render_image_full_v2(slide, outline, theme)：
  * 若 outline.image_path 存在且是文件：slide.shapes.add_picture(img, 0, 0, width=_SLIDE_WIDTH, height=_SLIDE_HEIGHT) 全幅铺满（强制铺满整页；生图按 1024x1024，轻微拉伸可接受）。
    用 left=Emu(0), top=Emu(0)（Emu 已 import）。
  * 图存在时：在底部叠加一个半透明深色标题带 + 标题/caption 浅色文字，保证文字可读。
    - 标题带：_add_shape(slide, MSO_SHAPE.RECTANGLE, left=Emu(0), top=Emu(int(_SLIDE_HEIGHT*0.78)), width=Emu(_SLIDE_WIDTH), height=Emu(int(_SLIDE_HEIGHT*0.22)), fill=theme.dark_bg_rgb, line=None)。
      若 _add_shape 不支持透明，就用实心 dark_bg_rgb 实色带即可（不要去碰 XML 搞 alpha，保持简单稳健）。
    - 标题文字：_add_text(..., outline.title, 浅色=theme.dark_text_rgb, font=theme.font_heading, bold, align left)，放在标题带内。
    - 若有 outline.caption：再加一行小字 theme.dark_muted_text_rgb。
  * 若 image_path 缺失/非文件：优雅降级 —— 直接 _fill_slide_bg + _add_title_block + 一个居中占位文案（参考 _render_image_v2 line 1198 的 placeholder 写法），不要崩。
  * 参考现有 v2 渲染器(如 _render_image_v2)的 import 名与 helper（_fill_slide_bg/_add_text/_add_shape/_add_title_block/_add_icon_badge/Inches/Emu/MSO_SHAPE）。
- _RENDERERS 映射加 "image_full": _render_image_full_v2。

== 改动 3：ppt_create 自动生图回填（核心）==
- 在 ppt_create 渲染循环【之前】、且仅当【非 dry_run 且 _HAS_PPTX】时，调用新 helper：
    _autofill_image_prompts(slides)
- 新增 def _autofill_image_prompts(slides: list[SlideOutline]) -> None：
  * 收集需要生图的：idx + prompt，条件 = so.image_prompt 非空 且 (not so.image_path)。
  * 若没有 → 直接 return（保证无 image_prompt 时零网络调用、纯离线，BC 不变）。
  * 有 → lazy import：try: from .image_tools import generate_images except Exception: log.warning(...); return（import 失败也不崩）。
  * 调 results = generate_images([p for _,p in 待生图])（批量一次）。
  * 按顺序把 results[k]["path"] 回填到对应 slides[idx].image_path（path 为 None 的项跳过，log.debug 该 prompt 生图失败原因）。
  * 整个函数包一层 try/except Exception → log.warning，绝不让生图问题中断 ppt_create（出图失败就走占位降级）。
  * 注意 SlideOutline 是 dataclass 且非 frozen（可直接赋值 so.image_path=...）。确认 normalize() 返回的对象可写（若 frozen 则用 dataclasses.replace；先确认——当前 class 未标 frozen，可直接赋值）。

# 结构合同范围

本目录定义新 AER 内部对象的结构草案；未覆盖全部SDK公共消息，不替换上游goal-resolution-v1。

所有身份、hash和scope由系统绑定。模型输出即使通过Schema，也必须通过来源回执、对象归属、当前权限、读集、状态与语义校验；schema中出现authoritative或APPLIED不是真实性证明。

时间采用UTC Unix毫秒整数，示例使用小数字说明顺序；生产数据必须符合真实时钟来源和期限规则。无新鲜度上限用null，不用0。整型上限只服务跨语言无损wire；内部计费仍按既有精确整数合同。哈希串是示例占位，不证明真实CAS对象存在。

本包未修改任何旧Schema或持久记录。

### 途中发现真缺陷 WBUI-DEF-AUTH-01（单列 r9-S15-defect-AUTH-01.md）
onboarding 完成后输入框停留「正在恢复身份…」，backend 每 30s 重试
companion_profile_bind 均被拒：trusted_relay_identity_unavailable。
根因链（全部实测）：keyring access_token 已过期 → backend control_ingress 调
/v1/me 得 401（r9-s01-cold.log 11 次）→ 而 cold-A 同窗口 200 OK（其身份早已 bound
不走 /v1/me）→ 打开账户面板触发**前端** 401→refresh→写回 keyring（面板拉到实时
数据证明前端链路通）→ 但 backend **仍旧 401**（启动时读 token 缓存内存，不重读）
→ 重启应用后 /v1/me **200 OK**、身份就绪。
⇒ 缺陷：backend 不重读/不刷新 token，且无用户可见的恢复入口；token 过期 + 未绑定
profile = 永久「正在恢复身份…」。恢复动作（打开账户面板+重启）均为真实 UI/生命周期
操作，非绕过。含账号信息的截图已按隐私纪律**删除不入账**。
本场景步骤1 判定面（onboarding+空态引导）在缺陷发生前已完整观测，判定不受影响。

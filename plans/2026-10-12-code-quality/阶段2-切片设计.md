# 阶段 2 切片设计：拆主入口

日期：2026-10-12（基于阶段 1 格式化后的代码，main.py 17311 行）
目标：main.py ≤ 1500 行，只留 FastAPI 组装、路由注册与 main()。

## 先决问题与顺序调整

- main.py 有 116 个模块级名字，其中 35 个在函数里用 `global` 重新绑定（SDK 入口、运行栈、伴侣与成长服务、各种延迟单例）。
- 函数搬到别的模块后，`from main import X` 拿到的是导入那一刻的对象，原模块后来重新绑定它不会传过去。直接搬会产生"看着能跑、实际读到旧对象"的缺陷。
- 所以计划里的 2.8（收状态）提到最前面，作为 2.0。

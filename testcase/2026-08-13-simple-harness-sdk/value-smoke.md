# Core value smoke inputs

昂贵构建与完整矩阵前先执行以下 3 个自然语言正向场景，全部走真实桌面入口与真实 Provider：

1. SDK-S1：`用一句话解释什么是幂等性。`
   - 价值门：准确、简洁、非空；无虚构 Tool/Workflow。
2. SDK-S2：`读取当前项目摘要，然后用中文告诉我重点。`
   - 价值门：确实读取 F1，一次 Tool，回答忠实且无 private canary。
3. SDK-S3 Run A：`分析这个项目的测试缺口，形成计划，执行获准的检查并给出可审计结论。`
   - 价值门：Agent 自主选择 durable_task；HITL、检查 receipt、结论、terminal delivery 一致。

任一场景只得到 partial/insufficient/空结果，立即停止昂贵收尾并报告 BLOCKED；不能用安全降级替代正向价值。

# TC-WB-17 — 规模与长文本边界（≥30 会话 / ≥30 产物 / 800×560）

> 对应 AC：WB-3（min 尺寸布局）、WB-5（会话列表）、WB-7（产物列表）边界面
> manual_required: true
> 前置造数：
> - 会话：通过 UI 或既有会话数据累积至 **≥30 个会话**；其中至少一个会话标题为 **120 字符无空格混排**长串（中英数字混排、无空格、无连字符，例如 `压力测试标题ABC123...` 拼够 120 字符；通过重命名入口设置）。
> - 产物：`<user_data>/artifacts` 目录预置 **≥30 个**带扩展名文件（`report-01.txt` … `report-30.txt`），`touch -t` 错开 mtime 保证倒序可判。

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 窗口缩至 **800×560**，展开侧栏「会话」区。 | 30+ 会话列表可**滚动**浏览到底部；排序仍为时间倒序（抽查首尾与已知创建顺序对照）。 |
| 2 | 观察 120 字符长标题条目。 | 长标题被**截断**显示（省略号或等价截断），**不破坏布局**：不撑宽侧栏、不把其他条目挤出可视区、无横向滚动条。 |
| 3 | 在 800×560 + 30 会话状态下核对「新建会话」入口。 | 新建入口**不被遮挡**、可见可点（列表再长也不吞掉入口）。 |
| 4 | 点击长标题会话加载。 | 正常加载消息记录；ChatView 头部条显示该标题（截断可）不破布局。 |
| 5 | 切到「📄产物」视图。 | 30+ 产物可滚动浏览；按 mtime 倒序（抽查首尾对照预置 mtime）。 |
| 6 | 保持 800×560，四视图（会话→技能→产物→设置）完整切换一轮。 | 每次切换流畅（无秒级卡死、无白屏）、无布局破坏、devtools 控制台无新增报错。 |

判定：步骤 1–6 全部满足才 PASS。

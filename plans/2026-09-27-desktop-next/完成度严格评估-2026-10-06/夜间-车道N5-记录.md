# 夜间车道 N5 记录：host_support 门面老红

- 工作树：`simple_harness-n5`，分支 `night-n5`，基线 main `3769cb8a`。
- 范围：`sdk/simple-harness-sdk/tests/orchestrator/host_support/`。

## 一、结论

- 17 条红全是夹具过时。不是产品缺陷。
- 原因：A′ 第 4 步（提交 `a4442c92`）删了旧执行池。编排器从此必须拿到部署给的原生执行池。`test_facade.py` 的 `_with` 夹具还直接 `Orchestrator(config, provider)`，没给执行池。
- 同目录其余 4 个文件（建任务入口、本地代码执行、审阅修补 S1、存储读视图）14 条本来就绿。无跳过、无预期失败。

## 二、改法（整组统一一处）

- 只改 `_with` 夹具。17 条用例的断言一字不动。
- 新夹具走 `agent_orchestrator.testing.product_world`。它就是产品那一份部署组装加原生执行池。
- 参数：`auto=False`、租户 `local`、主体 `我`、`max_concurrency=1`、`deployment_policy=OFF`、证据根仍是 `tmp_path/evidence`（预算账户计数直读这里的库）。
- `auto=False` 的理由：门面测试只建任务、读快照、取消。部署职责不能代签确认和授权去推进规划。
- 门面对象用 `world.control`。它就是部署绑定的那个门面，构造与旧夹具相同。
- `src/agent_orchestrator/testing/` 未改。产品源码未改。

## 三、每条用例守什么、守在哪里

| 用例 | 守的门面行为 | 守在哪里 |
|---|---|---|
| 开放字段往返（1 条） | 资料来源、种子文件、停止条件、预算原样存回快照 | `facade.py` 建任务字段解析与快照 |
| 字符串不当字符串列表（3 条） | 三个列表字段给字符串即拒，不建任务 | `facade.py` 严格字段校验 |
| 未知与已关闭字段按名拒绝（7 条） | 未知字段、已删字段（冲突预留、最终综合等）、金额预算按名拒，不建任务 | `facade.py` 严格字段校验 |
| 建任务回执持久、换内容即冲突（1 条） | 幂等键重放返回同一任务；内容不同报 `conflict` | `facade.py` 建任务（`MissionConflict` 映射） |
| 重复建任务不重复预留（1 条） | 重放不新增预算账户 | 编排器建任务幂等 + 预算账户表 |
| 外租户看不到（1 条） | 别人的任务与不存在的任务一律 `not_found`，消息相同 | `facade.py` `_mission` 租户校验 |
| 取消幂等（1 条） | 第一次 `changed=True`，第二次 `changed=False` | `facade.py` `cancel` |
| 快照游标同读（1 条） | 读快照中途别的连接写入的事件不算进 `through_seq`，预算用量同读 | `facade.py` 快照读视图 |
| 事件页大小有界（1 条） | 超上限报 `invalid_request` | `facade.py` 事件分页校验 |

## 四、改坏核验（证明换夹具后用例仍咬人）

- 做法：cp 备份 `facade.py`，改一处，清 `__pycache__`，重生成部署清单，跑本文件。恢复后再清缓存、重生成清单。
- 注意：不重生成清单时，部署字节校验先报"installed source bytes changed"，全组因错误原因变红。
- 结果：

| 改坏处 | 变红用例 | 其余 |
|---|---|---|
| 去掉租户校验 | 外租户看不到 | 16 绿 |
| 冲突改报 `invalid_request` | 建任务回执持久、换内容即冲突 | 16 绿 |
| 已结束任务取消报 `changed=True` | 取消幂等 | 16 绿 |
| 去掉事件页上限 | 事件页大小有界 | 16 绿 |

- 恢复后部署清单与提交版本逐字节一致（`git status` 只剩测试文件）。

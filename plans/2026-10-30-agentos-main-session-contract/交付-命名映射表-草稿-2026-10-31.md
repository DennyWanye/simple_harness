# 交付物：命名映射表（草稿，随任务书 C～F 合并逐项核对）

日期：2026-10-31 起草。用途：阶段 4 交付包的一部分。两家接入方（AgentOS 合同 v1.0、AIPhone 统一交接）用自己的词说需求，这张表告诉他们每个词在 SDK 里叫什么、在哪个公开接口上、哪些不做。
状态列：**已合并** = 在 main 上且有测试；**待合并** = 任务书已发、名字以任务书为准、合并后核对；**不做** = 见《不支持项》。

## 五、授权、取消、Goal（任务书 E，已合并 `27b8c8640`）

| 接入方的说法 | SDK 名字（按任务书 E） | 状态 |
|---|---|---|
| 宿主 hold / deny / 审批回调 | `AuthorizationPort.decide(AuthorizationRequest) → AuthorizationDecision.allow / needs_approval / deny`（只有异步一条路；可信字段由 SDK 注入；异常或超时 5 秒 = `authorization_required` 可重试；`allow(expires_at)` 可缓存，`revoke_authorization(grant_ref)` 立即失效）；默认 `AutoModeAuthorization`：auto 全放行，manual 只对 `connector_effect` 出卡片 | 已合并 |
| memory 式事务 / operation_key | 效果账本 `effects`：`EffectLedger.execute(connector, operation, target, params, operation_key=…)`，状态 `claimed / committed / not_committed / pending / unknown`；同 key 同参最多一个真实效果、异参 `idempotency_conflict`、缺回执保持 unknown 不重放 | 已合并 |
| 取消范围 | `session.cancel(target_kind ∈ goal / delegation / session_tree, target_id, *, command_id, expected_version?, reason)`：立即 `cancel_requested` + 屏障序号，收敛为 `cancelled / failed / unknown`；屏障后不派新活、屏障前交出去的如实标 `handed_off / completed / unknown`；屏障后用户新输入照常受理；`interrupt()` 只停当前回合；模型命令 `cancel` 只限本树 | 已合并 |
| 关闭 / 归档 | `close()` 只放手（任务继续）；`archive(*, command_id)` 有活报 `active_work`，归档后 `open_session` 报 `not_found_or_forbidden`，不删数据 | 已合并 |
| owner / fencing | `owner_generation` 持久单调递增，`host.status()` / `capabilities()` 暴露；第二进程公开入口报 `owner_conflict`（带代次）；旧 owner 失锁后拒绝新工作 | 已合并 |
| 恢复报告 | `session.recovery_report()`：`store_version / owner_generation / resumed_refs / waiting_approval_refs / held_refs / unknown_effect_refs / rejected_refs / reasons`，只读账本与任务库事实 | 已合并 |
| goal 版本 | `put_goal(spec, *, command_id, expected_version)` / `finish_goal(goal_id, outcome, *, command_id, expected_version, basis)` / `exclude_result(event_id, reason, *, command_id)`；根会话同时一个未收口 Goal；委派/子关系/输入/结果冻结 `goal_ref{goal_id, goal_version}`；收口只核结构事实，`succeeded` 要 `basis` | 已合并 |

## 六、动作工具（任务书 F，已合并 `cb9ed35d7`）

| 接入方的说法 | SDK 名字 | 公开接口 | 状态 |
|---|---|---|---|
| 主会话直接做有副作用的事 | 连接器操作声明 `OperationSpec.tool_roles=("main","child")` 后登记为工具 `<连接器>__<操作>`，目录 `source="action"`；只声明 `child` 或没声明 `main` 的不进目录；超过 `HostSettings.max_action_level` 的不进目录；任务池拿不到动作工具 | `OperationSpec.tool_roles`、`capabilities()["action_tools"]` | 已合并 |

| 稳定身份 / 重放 | 动作键按"回合 + 调用槽位"派生（换执行者重放同键）；同键异参 `idempotency_conflict`；无回执 `effect_unknown` 只对账不重做 | 回执字段 `operation_key` | 已合并 |
| 审批后执行、结果回流 | 过宿主 `AuthorizationPort`；人工模式或 `always_needs_approval` 发 `needs_response(request_kind="action")`；`respond(request_id, approve/deny, version)` 的同一事务写根库受理记录；跟进输入 `action_followup` 在原会话串行队列拿锁后执行；结果进收件箱 `source="action_result"`，`instruction=False`，下一句附资料或只读自动汇总 | `respond`、`inbox`、`queued_inputs` | 已合并 |
| 人工批准不放权 | 批准只解锁这一次动作，端口给的风险限制、`revision`、`expires_at` 原样保留 | — | 已合并 |
| 任务里的动作 | 仍走申请单 → 审阅 → 批准 → 执行器；匹配的任务回执在会话追事件时记入同一份 `effects`（沿用任务 `idempotency_key`） | `effects` 账本 | 已合并 |

## 七、不做（指向《不支持项》）

- store 迁移 / 回退 / opt.222 兼容调用（开发期，只有能力发现 + `incompatible_store_version`）。
- 一宿主多当事人（现阶段一个 SDK 实例 = 一个 Agent，只服务一个人，这个人由接入方维护）。
- 模型请求物理恰好一次（只保证可多算不可少算、同 key 不重复结算）。

== 背景(已实测) ==
- 本机 WPS COM 渲染可用: win32com.client.Dispatch("Kwpp.Application") → Presentations.Open(path, True, False, False) → pres.Slides(i).Export(png_path, "PNG", 1600, 900) 实测成功;MS PowerPoint COM 不可用(0x800700c1)。pywin32 已在 backend venv。
- 参考可工作脚本: G:\projects\deskpet\plans\2026-06-09-ppt-beauty-mainline\render_all_slides.py
- ppt_create 返回结构: {"ok":True,"path",...,"artifacts":[{kind:"file",...}]}。前端 ArtifactCard 对 kind="image" 会渲染缩略图(generate_image 工具已用此契约)。

== 新建文件 ==
G:\projects\deskpet\backend\deskpet\tools\ppt_render.py
内容:
1. def com_render_available() -> bool: 探测 pywin32 + Kwpp.Application 是否可 Dispatch(缓存结果到模块级 _AVAILABLE,只探一次;探测时 Dispatch 后立即 Quit;任何异常 → False)。
2. def render_pptx_to_pngs(pptx_path: str, out_dir: str, *, width: int = 1280, height: int = 720, max_slides: int = 30) -> list[str]:
   - COM 不可用/任何失败 → 返回 [](从不抛异常)。
   - pythoncom.CoInitialize() / finally CoUninitialize();Dispatch("Kwpp.Application");Open(绝对路径, ReadOnly=True, Untitled=False, WithWindow=False);逐页 Export 到 out_dir/slide{i}.png;Close;Quit(Quit 包 try)。
   - 返回成功导出的 png 路径列表(存在且 >1KB 才算)。
   - 模块顶部 lazy import win32com/pythoncom(import 失败 → _AVAILABLE=False,函数全部返回 [])。
   - 注意: COM 调用慢(WPS 启动数秒),调用方自行决定是否值得;本模块不做异步。

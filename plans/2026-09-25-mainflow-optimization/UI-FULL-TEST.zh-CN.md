# 完整 UI 交互测试（2026-09-25）

- 方式：只用电脑控制工具模拟人工鼠标和键盘（截图 → 看坐标 → 点击/输入）。数据库和日志只做只读核对。

- 环境：调试版应用包 `~/Applications/SimpleHarness.app`；数据目录 `.local-test-evidence/2026-09-25/opt/ui-full/`（全新，只拷入 `llm_runtime.json` 和 `config.toml`）；模型走 DeepSeek 本机转发，默认开思考。
- 判定：每一步写"期望"，实际对不上就记缺陷。能当场修的就修（改代码 → 重打包 → 重跑这一步），修不了的写进缺陷表。

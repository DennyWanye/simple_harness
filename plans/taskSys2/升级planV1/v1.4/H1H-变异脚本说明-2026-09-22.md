# H1-H 变异脚本说明

`run_h1h_mutations.py` 默认只打印变异定义，不复制、不打 patch、不运行 pytest。主代理后续可显式执行：

```bash
python plans/taskSys2/升级planV1/v1.4/run_h1h_mutations.py --run
python plans/taskSys2/升级planV1/v1.4/run_h1h_mutations.py --run --only 5
```

每次 `--run` 生成 UTC 时间戳 + UUID 的唯一 run 目录，`mkdir` 遇已存在目录直接拒绝，不会 `rmtree` 或覆盖原证据。每项从当前 SDK 复制完整 checkout 到 `.local-test-evidence/2026-09-22/h1h-mutations/<run-id>/mNN/`，保留 `LICENSES/`、`NOTICE*`、构建元数据和锁文件；只忽略 `.git`、`.venv`、旧 evidence、`__pycache__`、`*.pyc` 与常见 cache/build 目录。不修改 SDK 主树。

分类规则：唯一 testcase、pytest exit=1、无 JUnit `<error>`，且 failure traceback 最后的 `E ...:` 异常行是 `AssertionError` 或 pytest `Failed`（包括 `pytest.raises` DID NOT RAISE）才是 `KILLED`。已核对现有 pytest XML：默认 `<failure>` 可能没有 `type` attribute；runner 不再维护一份易遗漏的“接口异常白名单”。最终异常为 `OperationCompletionError`、`SourceUnavailable`、`CompilationRefused`、`AttributeError` 等任何非断言异常，都是 `INVALID`，并记录推导类型与 traceback。

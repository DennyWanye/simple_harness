== 改动 1：设计页分析 ==
新增 def _analyze_design_page(slide) -> dict：
- 递归收集有文字的形状(含 GROUP 内, shape.shape_type==6 时递归 shape.shapes)。
- 每形状求 max_pt：遍历 text_frame.paragraphs[*].runs[*].font.size 取最大 pt；无 size 则试 paragraph.font.size；都无默认 18。
- 分类(按勘探实证的字号/长度规律)：
  * title_shape: 在「文本长度<=60」的形状里取 max_pt 最大者(通常 92-162pt)。
  * body_slots: max_pt<=32 且 文本长度>=25 的形状，按(top,left)阅读序排序 —— 这些是英文 lorem 正文槽。
  * label_slots: max_pt<=32 且 文本长度<25(如 ONE/EXPERIENCE/QUOTE)。
  * subtitle_shape: 除 title 外 max_pt 第二大的形状(若有)。
- 返回 {"title": shape|None, "subtitle": shape|None, "bodies": [...], "labels": [...], "n_body": int, "title_pt": float}。
- 从不抛异常(单形状异常跳过)。

== 改动 2：保留样式的文字替换 ==
新增 def _set_text_keep_style(shape, lines: list[str]) -> None：
- 目标：替换文字但保留原 run 的字体/字号/颜色/加粗。
- 做法(lxml 层)：tf=shape.text_frame；取第一个有 run 的段 p0 与其第一个 run r0(保留其 rPr 格式)；
  * r0.text = lines[0]；删 p0 其余 run(r._r.getparent().remove(r._r))；
  * 删其余所有段(<a:p> 移除)；
  * lines[1:] 每行: copy.deepcopy(p0._p) → 把副本中 run 文本设为该行 → append 到 txBody。
- lines 为空或 [""] → 清空文本(tf.text="")。
- 每行裁剪到 80 字符(防爆框)。从不抛异常。

== 改动 3：设计页渲染器 ==
新增 def _render_with_design_pages(slides, template_path, *, title, author, out_path) -> Optional[dict]：
1. prs = _Presentation(template_path)；若 len(prs.slides) < 3 → return None(设计页太少,让上层回退 layout 模式)。
2. 逐设计页 _analyze_design_page 建索引；页分类：
   * cover = slide[0]；
   * section_pages: title_pt>=80 且 n_body<=1 的页(排除cover)；
   * content_pages: n_body>=1 的页(排除cover)，记 n_body。
3. 为每个 outline 项选页(贪心,每页最多用一次)：
   * layout=title → cover。
   * section/quote → 未用 section_pages 取一个；没了→未用 content 页。
   * bullet/toc/chart/image/image_full → 未用 content 页中选 n_body 最接近(优先>=) len(bullets) 的。
   * two_column → 未用 content 页中 n_body>=2 优先。
   * 全用完 → 任意未用页；一个未用页都没有 → 该项跳过选页循环并 log.debug(总页数通常 15-18 >> outline 4-8,罕见)。
4. 填充(每个选中页)：
   * title 项: _set_text_keep_style(title_shape,[so.title]); subtitle→subtitle_shape 或第一个 body；其余 body 槽清空(它们是英文lorem,留着穿帮)。
   * section: title→title_shape; subtitle→第一个 body 或 subtitle_shape；其余 body 清空。
   * quote: so.quote→title_shape; so.cite→第一个 label 或 body；其余 body 清空。
   * bullet/toc: so.title→title_shape; bullets 分配进 body_slots —— n_body>=len(bullets): 每槽一条,多余槽清空; n_body<len(bullets): 前 n-1 槽各一条,最后一槽放剩余条目(多行 lines)。label_slots 不动(ONE/TWO 当装饰编号)。
   * two_column: title→title_shape; 槽0 = [left_title]+left 多行; 槽1 = [right_title]+right 多行；其余清空。
   * image/image_full: 当 bullet 处理(标题+caption 进 body)；若 so.image_path 是文件且页内有 PICTURE 占位符则 insert_picture(可选,没有就算了)。
   * notes: so.notes → slide.notes_slide.notes_text_frame.text。
5. 重排+删页：
   * 把【选中页】按 outline 顺序重排：操作 prs.slides._sldIdLst —— 收集选中页对应 sldId 元素按新序 append(lxml append 自动移动)，再删未用页(先 drop_rel 再 remove,姿势见上)。
6. core_properties title/author；prs.save(out_path)；返回与 _render_with_template 相同结构的 dict(theme 用 "template-design")。
7. 整函数 try/except → log.warning + return None(上层回退)。

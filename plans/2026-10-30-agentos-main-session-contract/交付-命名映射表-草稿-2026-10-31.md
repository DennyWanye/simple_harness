# 交付物：命名映射表（草稿，随任务书 C～F 合并逐项核对）

日期：2026-10-31 起草。用途：阶段 4 交付包的一部分。两家接入方（AgentOS 合同 v1.0、AIPhone 统一交接）用自己的词说需求，这张表告诉他们每个词在 SDK 里叫什么、在哪个公开接口上、哪些不做。
状态列：**已合并** = 在 main 上且有测试；**待合并** = 任务书已发、名字以任务书为准、合并后核对；**不做** = 见《不支持项》。

## 七、不做（指向《不支持项》）

- store 迁移 / 回退 / opt.222 兼容调用（开发期，只有能力发现 + `incompatible_store_version`）。
- 一宿主多当事人（现阶段一个 SDK 实例 = 一个 Agent，只服务一个人，这个人由接入方维护）。
- 模型请求物理恰好一次（只保证可多算不可少算、同 key 不重复结算）。

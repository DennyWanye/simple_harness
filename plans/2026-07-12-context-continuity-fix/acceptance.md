# 验收标准：上下文连续性与图片误触发修复

## 范围

- 修复近期对话读取、当前消息重复、L2 与慢速 L3 共同失败、澄清轮误暴露图片工具。
- 为“已生成图片”类回复增加真实工具证据约束。
- 保持显式图片生成请求、其他工具任务、长期记忆和既有会话持久化能力可用。

## 功能验收条款

| ID | 功能点 | 可验证条件 | 优先级 |
|---|---|---|---|
| AC-1 | 最近消息 | 会话超过 `limit` 后，读取结果为最后 N 条且仍按时间正序排列 | 必须 |
| AC-2 | 当前轮去重 | 当前用户消息先落库时，最终模型 messages 中该消息只出现一次 | 必须 |
| AC-3 | L2 故障隔离 | L3 检索超时或失败时，当前 session 的 L2 连续历史仍进入 bundle.history | 必须 |
| AC-4 | 澄清轮工具收敛 | “是一个脉冲步枪”这类依赖前文的短澄清轮不暴露 `generate_image` | 必须 |
| AC-5 | 显式生图兼容 | 明确要求“生成/画一张图片”时仍暴露并可调用 `generate_image` | 必须 |
| AC-6 | 完成声明证据 | 未发生成功 `generate_image` 调用时，不得向用户声称图片已经生成 | 必须 |
| AC-7 | 原问题真机闭环 | 真机新会话输入武器调研问题，再输入“是一个脉冲步枪”，回复继续做武器识别/调研且不声称生成图片 | 必须 |

## 非功能与边界

- 不清理或覆盖工作树内其他未提交修改。
- MemoryAssembler 单组件 1.5 秒预算仍有效；慢速 L3 降级不得拖垮 L2。
- 工具调用与结果配对、消息时间正序、thinking `reasoning_content` 兼容性保持不变。
- 自动化测试与 Windows 真机点击测试均需通过；完成后同步 STATUS。

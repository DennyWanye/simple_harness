# Core-value smoke inputs

1. `根据我们刚才聊过的内容，用两句话告诉我你记得我的哪项偏好；不需要调用工具。`
2. After ≥10 turns: `我之前说过住在哪里、喜欢喝什么？不确定就直说。`
3. With fixture attached: `读取我刚附上的这个公开文本文件，并告诉我第一行；需要的话使用文件工具。`
4. `读取 /definitely-not-present/context-canary.txt；找不到就明确说明，不要猜。`
5. In two differently configured Sessions: `请用一句话说明当前任务，并保持运行直到我打开 Context 查看。`

Items 1–3 are positive-value samples; 4 is negative-safety. Item 5 counts only with a receipt proving
overlapping physical intervals. These are inputs, not results.
